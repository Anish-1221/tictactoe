Tic-tac-toe for N players

CS 6364 project: minimax and alpha-beta pruning, from two players to three

Five implementations, from the two-player 3×3 game solved exhaustively by minimax up to a 10×10 board played by three machine players. On every board, three in a row, a column or a diagonal wins. Plain HTML, CSS and JavaScript throughout: no build step and no server.

Task 1

The supplied sample

3×3, you against the machine, plain minimax with no pruning.

 Task 2

Alpha-beta pruning

Same game, 98.8% fewer nodes, with moves ordered by how many open paths run through each cell. All three counts shown on every move.

 Task 3

Machine against machine

Two agents, N games, a win and loss tally, and a search depth control for each side.

 Task 4

Three players on 4×4

Alpha-beta with three players, each assuming the other two are against it. maxn available for comparison.

 Task 5

Scaling to B×B

Boards up to 10×10, three in a row to win, with the search heuristics exposed as controls.
