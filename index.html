Tic-tac-toe for N players

CS 6364 project — minimax, alpha-beta pruning and maxn

Five implementations, from the two-player 3×3 game solved exhaustively by minimax up to a 10×10 board played by three machine players. Plain HTML, CSS and JavaScript throughout: no build step and no server.

Task 1

The supplied sample

3×3, you against the machine, plain minimax with no pruning.

 Task 2

Alpha-beta pruning

Same game, same moves, 96% fewer nodes. Both counts shown on every move.

 Task 3

Machine against machine

Two agents, N games, a win and loss tally, and a search depth control for each side.

 Task 4

Three players on 4×4

Minimax does not generalise past two players, so this uses maxn.

 Task 5

Scaling to B×B

Boards up to 10×10 with the search heuristics exposed as controls.

Source

Code at github.com/Anish-1221/tictactoe. The Task 1 sample is from Artificial Intelligence in Game Development, published by Packt and MIT licensed.
