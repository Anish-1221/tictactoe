About this task

Two machine players, both using depth-limited alpha-beta with the same move ordering as Task 2. At depth 9 a player searches to the end of the game and plays perfectly, so two depth-9 players draw every time. That's expected for 3×3. Lower one player's depth to get wins and losses.

Below depth 9 the search stops early and scores the board with a heuristic: for each line with none of the opponent's marks, add the square of the player's marks in it, then subtract the same for the opponent.

Equally good moves are picked at random, otherwise all N games would be identical. At the root, every move is searched with a full window so that ties are real ties: under pruning, a score equal to alpha only means "no better", and treating those as ties made a depth-9 player lose games.
