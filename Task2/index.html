About this task

Same game as Task 1, but the machine uses alpha-beta pruning instead of plain minimax. It picks a move of the same value while looking at far fewer positions. With the compare box ticked, every machine move also runs alpha-beta without move ordering and plain minimax on the same board, so all three node counts can be compared. From an empty board: 549,946 for minimax, 20,866 for alpha-beta, 6,347 for alpha-beta with ordering.

Pruning: alpha is the best score the machine can already get elsewhere in the tree, beta the best the human can. Once alpha >= beta, the parent would never choose this branch, so the rest of its moves are skipped. Each skip is a cutoff.

Move ordering: cells are tried in order of how many open paths run through them, i.e. lines the opponent hasn't blocked. On an empty board that's the centre (4), then corners (3), then edges (2). Good moves early means more cutoffs.

The machine plays perfectly, so a draw is the best you can do.
